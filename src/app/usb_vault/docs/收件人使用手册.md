# 《图书资料》U盘 使用手册（收件人版）

> 初版 v1.0 · 2026-09-20 · 配套图书阅览器 v2.3.3
> 窗口标题栏会显示版本号（如 v2.3.3），联系支持时请一并告知。

## 一、您收到了什么

| 物品 | 说明 |
|---|---|
| U盘 ×1 | 资料已加密装入，附带 Windows / Mac 两套阅览器，插上即用，无需安装任何软件 |
| 解锁码 ×1（如发件方设置） | 8 位，形如 `XXXX-XXXX`，开机阅读时输入一次 |

**请将解锁码与U盘分开保管**，不要存放在同一处。

## 二、Windows 电脑上使用

1. 将U盘插入电脑。
2. 打开"此电脑"中名为 **图书资料** 的U盘。
3. 双击盘中的 **图书阅览器** 程序（若是一个文件夹，打开后双击里面的同名程序）。
4. 若弹出解锁码输入框：输入码卡上的 8 位码 → 确定。
5. 左侧列表即资料目录，**双击** 条目即可打开阅读。

## 三、Mac 电脑上使用

1. 将U盘插入电脑。桌面上会出现两个卷：**图书资料** 与 **图书阅览器Mac**。
   - **图书资料** 卷在 Mac 上看起来是空的——这是正常的，资料加密存放在里面。
2. 打开 **图书阅览器Mac** 卷，双击 **图书阅览器.app**。
3. 若系统提示"无法验证开发者"：在图标上**右键 → 打开**，再点"打开"确认（仅需一次）。
4. 输入解锁码（如有）。
5. 接着会弹出一个密码输入框：**输入您 Mac 的开机密码**。
   这是系统授权阅览器读取U盘序列号（资料与这只U盘绑定的验证步骤），密码不会被记录或发送。输错可重试，最多 3 次。
6. 通过后左侧列表即资料目录，双击打开阅读。

## 四、阅读操作

| 操作 | 方法 |
|---|---|
| 打开资料 | 左侧列表中**双击**条目 |
| PDF 翻页 | 窗口下方 **上一页 / 下一页** 按钮，页码同步显示 |
| 放大缩小 | 底部**缩放滑杆**（25%–400%）；或按住 **Ctrl + 滚动鼠标滚轮**（以鼠标位置为中心）；或 **＋ / － / 100%** 按钮 |
| 支持的格式 | PDF、图片（jpg/png 等）、文本直接阅读；Word/Excel/PPT 等文档已自动转换为 PDF；其他格式仅显示文件基本信息 |

大文件首次打开需渲染几秒，属正常等待；缩放过程若有短暂延迟，等待即会清晰。

## 五、这些情况是正常保护，不是故障

| 现象 | 原因 |
|---|---|
| 无法复制、另存、拖出文件 | 资料保护设计，阅览器内不存在这些操作 |
| 截图 / 录屏拍到阅览器是黑块 | 同上，防拍屏保护 |
| 把资料拷到其他U盘或电脑后打不开（提示"仅限指定U盘使用"） | 资料与这只U盘唯一绑定，拷贝件无效 |
| Mac 上"图书资料"卷看起来是空的 | 资料加密且隐藏存放，请从"图书阅览器Mac"卷进入 |

**请勿删除盘中任何文件、请勿格式化U盘**——阅读器或资料一旦删除无法自行恢复（需发件方重新烧录），格式化会永久销毁全部资料。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 提示解锁码不正确 | 核对码卡上 8 位码是否输对（注意区分易混字符）；连续 3 次不对请联系发件方 |
| 提示"资料已过期" | 资料设有有效期，请联系发件方 |
| 提示"仅限指定U盘使用" | 只能在这只U盘上使用，拷贝到别处无效 |
| Mac 双击 .app 无反应 | 改用**右键 → 打开**；仍无反应则拔下U盘重插再试 |
| Mac 密码框不确定是否该输 | 该框用于读取U盘序列号的系统授权（见第三节第 5 步），可先联系发件方核实再输入 |
| 电脑上不显示U盘 | 换一个 USB 接口；换台电脑排除接口问题；Mac 可打开"磁盘工具"查看 |
| 打开后列表为空或报"打开失败" | 记录窗口标题版本号，联系发件方 |

## 七、保管与支持

- U盘避免摔落、进水、高温、强磁场；长期不用请妥善存放。
- 解锁码与U盘**分开存放、分开携带**。
- 有效期、使用范围以交付说明为准；任何问题请联系发件方，并告知窗口标题中的版本号。
