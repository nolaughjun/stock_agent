# 《图书资料》U盘 使用手册（收件人版）

> v1.14 · 2026-10-02 · 配套图书阅览器 v2.4.11（v1.14 起，Mac 阅读入口按电脑芯片分为两个：**Apple 芯片（M 系列）用"（适配MAC-Apple芯片）"版，Intel 处理器用"（适配MAC-Intel芯片）"版**，查看方法见第三节第 1 步；v1.13 起，把阅览器整个文件夹拷贝到电脑的任何位置（桌面、硬盘等）都无法打开，即使U盘当时插在这台电脑上，同样提示"脱离U盘介质"，属正常保护；v1.12 起，U盘在 Mac 电脑上使用过后，回到 Windows 可能多显示一个名为 .资料存储 的空白盘符，属正常现象，不影响阅读；v1.11 起，盘中文件受系统级防删除保护：删除、改名、移动会被 Windows 直接拒绝，属正常现象；v1.10 起，Mac 上可能显示一个以"."开头的加密存储卷，打开后是空的，属正常现象；v1.9 起，文件夹默认只显示书名程序一个入口，其余为隐藏的支撑文件，请勿删除或改名；v1.8 起，单独拷贝盘中书名程序到其他电脑，同样提示"脱离U盘介质"；v1.7 起，盘中阅览器入口名称改为"（适配Windows系统）/（适配MAC系统）"后缀；v1.6 起，阅览器拷贝到其他电脑无法打开时的提示明确为"脱离U盘介质"；v1.5 起，全面适配高分辨率屏幕和平板电脑，左侧目录宽度可自由调整）
> 窗口标题栏会显示版本号（如 v2.4.11），联系支持时请一并告知。

## 一、您收到了什么

| 物品 | 说明 |
|---|---|
| U盘 ×1 | 资料已加密装入，附带 Windows 与 Mac 阅览器（Mac 分 Apple 芯片 / Intel 芯片两种），插上即用，无需安装任何软件 |
| 解锁码 ×1（如发件方设置） | 8 位，形如 `XXXX-XXXX`，开机阅读时输入一次 |

**请将解锁码与U盘分开保管**，不要存放在同一处。

## 二、Windows 电脑上使用

（需 Windows 10 及以上系统；Windows 7 / 8 电脑无法运行阅览器）

1. 将U盘插入电脑。
2. 打开"此电脑"中名为 **图书资料** 的U盘。
3. 打开盘中的 **《欧阳竟无全集》《桂伯华全集》图书阅览器（适配Windows系统）** 文件夹，
   双击里面的 **《欧阳竟无全集》《桂伯华全集》** 程序。
   文件夹里的其他文件（部分默认不显示）是程序运行所需的支撑文件，
   无需理会，也不要删除或改名。
   盘里还有名为 **《欧阳竟无全集》《桂伯华全集》图书阅览器（适配MAC-Apple芯片）.app** 和
   **《欧阳竟无全集》《桂伯华全集》图书阅览器（适配MAC-Intel芯片）.app** 的文件夹，
   那是给 Mac 电脑同事用的入口（按芯片分两种），Windows 上无需打开它们，也不要删除或改名。
4. 若弹出解锁码输入框：输入码卡上的 8 位码 → 确定。
5. 左侧列表即资料目录，**双击** 条目即可打开阅读。

## 三、Mac 电脑上使用

1. 将U盘插入电脑。桌面上会出现 **图书资料** 一个卷。
   - **图书资料** 卷里有 **Mac 阅读入口**（按芯片分两个：**《欧阳竟无全集》《桂伯华全集》图书阅览器（适配MAC-Apple芯片）.app** 与
     **《欧阳竟无全集》《桂伯华全集》图书阅览器（适配MAC-Intel芯片）.app**）和
     **《欧阳竟无全集》《桂伯华全集》图书阅览器（适配Windows系统）** 文件夹（Windows 同事的入口，Mac 上无法运行，无需打开）；
   - 资料加密存放在另一个加密存储卷里。不同 Mac 电脑表现不一：多数不显示；
     若桌面上出现一个以"."开头的卷（如 .资料存储），**打开后是空的，属正常现象**，
     请勿格式化或删除其中内容。
2. **先确认您 Mac 的芯片**（决定用哪个入口）：点屏幕左上角 **苹果菜单 → 关于本机**——
   显示 **芯片** 为 **Apple M 系列**（如 Apple M1 / M2 / M3）→ 用
   **（适配MAC-Apple芯片）** 版；显示 **处理器** 为 **Intel**（如 Intel Core i5）→ 用
   **（适配MAC-Intel芯片）** 版。不确定时把"关于本机"页面拍照联系发件方即可。
3. 打开 **图书资料** 卷，双击与您芯片对应的那个 .app 入口。
4. 若系统提示"无法验证开发者"：在图标上**右键 → 打开**，再点"打开"确认（仅需一次）。
5. 输入解锁码（如有）。
6. 接着会弹出一个密码输入框：**输入您 Mac 的开机密码**。
   这是系统授权阅览器读取U盘序列号（资料与这只U盘绑定的验证步骤），密码不会被记录或发送。输错可重试，最多 3 次。
7. 通过后左侧列表即资料目录，双击打开阅读。

## 四、阅读操作

| 操作 | 方法 |
|---|---|
| 打开资料 | 左侧列表中**双击**条目 |
| 调整左侧目录宽度 | 拖动目录与正文之间的**竖分隔条**；或点目录右上方的 **◀ / ▶** 按钮（每次调整一档）。文件名显示不全时可调宽，想多看正文时可调窄 |
| PDF 翻页 | 窗口下方 **上一页 / 下一页** 按钮，页码同步显示 |
| 直接翻到某一页 | 在翻页按钮右侧的**页码框**中输入页码后**按回车**（或点 **跳转**）。输错时会出现"请输入 1～总页数 之间的页码"提示，重新输入即可 |
| 页面缩略图 | 打开 PDF 后，正文左侧自动出现**整本页面的缩略图**（从上往下依次排列，加载需要一两秒属正常）。**点击任一缩略图直达该页**；翻页时蓝框高亮会跟着走。点面板右上角 **×** 可收起，勾选工具栏 **缩略图** 即可恢复 |
| 放大缩小 | 底部**缩放滑杆**（25%–400%）；或按住 **Ctrl + 滚动鼠标滚轮**（以鼠标位置为中心）；或 **＋ / － / 100%** 按钮 |
| 支持的格式 | PDF、图片（jpg/png 等）、文本直接阅读；Word/Excel/PPT 等文档已自动转换为 PDF；其他格式仅显示文件基本信息 |

大文件首次打开需渲染几秒，属正常等待；缩放过程若有短暂延迟，等待即会清晰。

## 五、这些情况是正常保护，不是故障

| 现象 | 原因 |
|---|---|
| 无法复制、另存、拖出文件 | 资料保护设计，阅览器内不存在这些操作 |
| 截图 / 录屏拍到阅览器区域是黑块 | 防拍屏保护；若个别工具仍能拍到内容，请勿外传截图并联系发件方 |
| 把阅览器拷贝到其他电脑或本机任何位置（桌面、硬盘等）后打开，提示"脱离U盘介质，加密书稿无法在该设备上打开查看"（即使U盘当时插在这台电脑上也一样，v2.4.8 起） | 属正常保护：阅览器只能从U盘上打开，请回到U盘上的阅览器阅读 |
| 把资料拷到其他U盘或电脑后打不开（提示"仅限指定U盘使用"） | 资料与这只U盘唯一绑定，拷贝件无效 |
| Mac 上显示出一个以"."开头的卷（如 .资料存储） | 加密存储卷，不同 Mac 电脑表现不一（多数不显示），打开后是空的，属正常现象，请勿删除或格式化 |
| 在 Mac 上使用过U盘后，回到 Windows 时"此电脑"里多出一个名为 .资料存储 的盘符（打开是空的） | 属正常现象（Mac 系统改写U盘分区信息所致），不影响阅读，无需处理，请勿删除或格式化 |
| Windows 上看到"《欧阳竟无全集》《桂伯华全集》图书阅览器（适配MAC-Apple芯片）.app"和"（适配MAC-Intel芯片）.app"文件夹 | 这是 Mac 电脑同事的阅读入口（按芯片分两种），Windows 无需打开，也不要删除或改名 |
| 删除、改名或移动盘中文件/文件夹时，系统提示"拒绝访问"或"需要权限" | **防删除保护在正常起作用（v1.11 起的新U盘）**：系统会直接拒绝这些操作，阅读不受任何影响。这不是故障，请勿尝试解除 |

**请勿删除盘中任何文件、请勿格式化U盘**——阅读器或资料一旦删除无法自行恢复（需发件方重新烧录），格式化会永久销毁全部资料。（v1.11 起的新U盘，系统会直接拒绝删除/改名/移动操作；请勿自行设法绕过，绕过后误删的文件同样无法恢复。）

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 提示解锁码不正确 | 核对码卡上 8 位码是否输对（注意区分易混字符）；连续 3 次不对请联系发件方 |
| 提示"资料已过期" | 资料设有有效期，请联系发件方 |
| 提示"仅限指定U盘使用" | 只能在这只U盘上使用，拷贝到别处无效 |
| Mac 双击 .app 无反应 | 先核对是否选对入口（见第三节第 2 步：Apple 芯片 / Intel 用不同入口，选错会打不开）；入口无误则改用**右键 → 打开**；仍无反应则拔下U盘重插再试 |
| Mac 双击 .app 提示"无法打开"或闪退 | 多半是芯片与入口不匹配：按第三节第 2 步查看"关于本机"，换另一个 Mac 入口再试 |
| Mac 密码框不确定是否该输 | 该框用于读取U盘序列号的系统授权（见第三节第 6 步），可先联系发件方核实再输入 |
| 电脑上不显示U盘 | 换一个 USB 接口；换台电脑排除接口问题；Mac 可打开"磁盘工具"查看 |
| 双击阅览器提示"缺少 api-ms-win-*.dll"或无法启动 | 电脑系统过旧：阅览器需 **Windows 10 及以上**，Windows 7 / 8 不受支持，请换用新系统电脑 |
| 在U盘上双击书名程序，提示"阅览器文件不完整，请联系发件方重新烧录U盘" | 盘上文件受损（如被杀毒软件隔离），记录窗口提示与版本号，联系发件方换新盘 |
| 平板 / 高分屏上左侧列表显示不全或按钮过小 | 需 **v2.4.3 及以上**版本：请先看窗口标题版本号，低于 v2.4.3 请联系发件方换新盘 |
| 打开后列表为空或报"打开失败" | 记录窗口标题版本号，联系发件方 |

## 七、保管与支持

- U盘避免摔落、进水、高温、强磁场；长期不用请妥善存放。
- 解锁码与U盘**分开存放、分开携带**。
- 有效期、使用范围以交付说明为准；任何问题请联系发件方，并告知窗口标题中的版本号。
