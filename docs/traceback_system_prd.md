## 1. 产品背景

### 1.1 问题描述

在安全运营过程中，当发生安全事件（如勒索病毒感染、数据泄露、APT攻击等）时，安全团队面临以下挑战：

| 痛点 | 具体表现 | 影响 |
|-----|---------|------|
| **分析效率低** | 人工查看多类日志，耗时数小时甚至数天 | 响应延迟，损失扩大 |
| **技术门槛高** | 需要精通流量分析、逆向工程、威胁情报等多领域技能 | 人才短缺，培养成本高 |
| **信息碎片化** | 数据分散在多个系统，难以形成完整攻击链 | 分析不全面，遗漏关键线索 |
| **知识难以沉淀** | 溯源经验依赖个人，难以传承复用 | 重复造轮子，效率无法提升 |
| **报告质量参差** | 溯源报告格式不统一，内容不完整 | 无法有效支撑决策和响应 |

### 1.2 产品定位

溯源分析系统是一个基于 AI 大模型的安全事件溯源分析平台，通过智能体协作实现：

- **自动化证据收集**：从多源数据中自动提取关键证据
- **智能攻击链还原**：自动构建攻击时间线，还原攻击路径
- **威胁归因分析**：关联威胁情报，识别攻击者特征
- **标准化报告生成**：自动产出专业溯源分析报告

**核心价值主张**：输入安全事件，自动完成溯源分析并生成报告

### 1.3 产品目标

| 目标类型 | 目标描述 | 衡量指标 |
|---------|---------|---------|
| 效率目标 | 缩短溯源分析时间 | 平均分析时间 < 30分钟 |
| 质量目标 | 提升溯源报告质量 | 报告完整度评分 > 85分 |
| 覆盖目标 | 支持常见攻击类型 | 覆盖 80% 以上常见攻击场景 |
| 可用目标 | 降低使用门槛 | 初级分析师可独立完成分析 |

## 3. 用户故事

### US-001: 创建溯源分析任务

**作为** 一名安全运营工程师  
**我想要** 快速创建溯源分析任务，关联相关告警和资产  
**以便于** 启动自动化溯源分析流程

**验收标准**:
- [ ] 支持手动输入事件基本信息（事件名称、描述、时间范围）
- [ ] 支持关联告警ID，自动拉取告警详情
- [ ] 支持指定涉及资产（IP、主机名、用户账号）
- [ ] 支持上传相关附件（PCAP、日志文件、样本文件）
- [ ] 创建后自动进入分析队列

**优先级**: P0  
**故事点**: 3

---

### US-002: 自动化证据收集

**作为** 一名安全分析师  
**我想要** 系统自动从多个数据源收集相关证据  
**以便于** 节省手动查询时间，确保数据完整性

**验收标准**:
- [ ] 支持从SIEM系统查询相关日志
- [ ] 支持从EDR获取终端行为数据
- [ ] 支持查询DNS解析记录
- [ ] 支持查询流量日志（NetFlow/PCAP）
- [ ] 支持查询威胁情报（IP/域名/Hash信誉）
- [ ] 证据按类型自动分类存储
- [ ] 生成证据收集报告

**优先级**: P0  
**故事点**: 8

- [ ] 支持时间线可视化展示
- [ ] 支持时间线缩放和筛选
- [ ] 支持事件详情查看
- [ ] 支持人工补充和修正

**优先级**: P0  
**故事点**: 5

### US-004: 攻击链还原

**作为** 一名安全分析师

**以便于** 理解攻击手法，指导防护加固

**API 调用示例**：

```python
# timesketch_client.py
import requests
from typing import List, Dict

class TimesketchClient:
    """Timesketch API 客户端"""
    
    def __init__(self, host: str, api_key: str):
        self.base_url = f"{host}/api/v1"
        self.headers = {"Authorization": f"Bearer {api_key}"}
    
    async def create_timeline(self, name: str, description: str) -> str:
        """创建时间线"""
        response = requests.post(
            f"{self.base_url}/sketches/",
            headers=self.headers,
            json={"name": name, "description": description}
        )
        return response.json()["objects"][0]["id"]
    
    async def upload_events(self, timeline_id: str, events: List[Dict]) -> bool:
        """上传事件到时间线"""
        # Timesketch 支持 CSV/JSONL 格式导入
        response = requests.post(
            f"{self.base_url}/sketches/{timeline_id}/event/",
            headers=self.headers,
            json={"events": events}
        )
        return response.status_code == 200
    
    async def search_events(self, timeline_id: str, query: str) -> List[Dict]:
        """搜索时间线事件"""
        response = requests.get(
            f"{self.base_url}/sketches/{timeline_id}/event/",
            headers=self.headers,
            params={"query": query}
        )
        return response.json()["objects"]
    
    async def get_timeline_view(self, timeline_id: str) -> Dict:
```

```python
    def _load_rules(self, rules_dir: str) -> yara.Rules:
        """加载 YARA 规则"""
        rule_files = {}
        for root, _, files in os.walk(rules_dir):
            for f in files:
                if f.endswith(".yar") or f.endswith(".yara"):
                    path = os.path.join(root, f)
                    rule_files[f] = path
        return yara.compile(filepaths=rule_files)
    
    async def scan_file(self, file_path: str) -> List[Dict]:
        """扫描文件"""
        matches = self.rules.match(file_path)
        return [
            {
                "rule": m.rule,
                "namespace": m.namespace,
                "tags": m.tags,
                "meta": m.meta,
                "strings": [s[1] for s in m.strings]
            }
            for m in matches
        ]
    
    async def scan_directory(self, dir_path: str) -> Dict[str, List[Dict]]:
        """扫描目录"""
        results = {}
        for root, _, files in os.walk(dir_path):
            for f in files:
                file_path = os.path.join(root, f)
                matches = await self.scan_file(file_path)
                if matches:
                    results[file_path] = matches
        return results
    
    async def scan_memory_dump(self, memory_path: str) -> List[Dict]:
        """扫描内存镜像"""

        matches = self.rules.match(file_path=memory_path)
```

#### 9.16.4 统一组件管理器

```python
# component_manager.py
from typing import Dict, Type
import asyncio

class ComponentManager:
    """开源组件统一管理器"""
    
    def __init__(self):
        self._components: Dict[str, BaseAdapter] = {}
        self._configs: Dict[str, Dict] = {}
    
    def register(self, name: str, adapter_class: Type[BaseAdapter], config: Dict):
        """注册组件"""
        self._configs[name] = config
    
    async def initialize(self):
        """初始化所有组件"""
        init_tasks = []
        for name, adapter_class in self._components.items():
            config = self._configs.get(name, {})
            adapter = adapter_class(**config)
            init_tasks.append(self._init_component(name, adapter))
        
        await asyncio.gather(*init_tasks, return_exceptions=True)
    
    async def _init_component(self, name: str, adapter: BaseAdapter):
        """初始化单个组件"""
        try:
            connected = await adapter.connect()
            if connected:
                self._components[name] = adapter
                await adapter.health_check()
        except Exception as e:
            # 组件初始化失败处理
            pass
    
    def get(self, name: str) -> BaseAdapter:
        """获取组件实例"""
        return self._components.get(name)
    
    async def health_check_all(self) -> Dict[str, bool]:
        """检查所有组件健康状态"""
        results = {}
        for name, adapter in self._components.items():
            try:
                results[name] = await adapter.health_check()
            except:
                results[name] = False
        return results
```
