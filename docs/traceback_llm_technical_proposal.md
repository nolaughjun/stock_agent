## 1. 项目背景与目标

### 1.1 项目背景

目前主流安全厂商的 AI 能力主要集中在威胁检测、恶意软件分析、安全问答辅助，缺乏专门针对溯源分析场景的安全大模型。

**市场空白**：
- 攻击链自动还原
- 威胁归因分析
- 时间线智能构建
- 溯源报告自动生成

### 1.2 项目目标

| 目标类型 | 描述 | 衡量指标 |
|---------|------|---------|
| 核心目标 | 打造溯源分析专用大模型 | 覆盖溯源分析全流程 |
| 性能目标 | 攻击链还原准确率 | > 85% |
| 效率目标 | 溯源分析时间 | < 30分钟 |
| 差异化目标 | 填补市场空白 | 业界首个溯源专用大模型 |

## 2. 整体架构设计

### 2.1 分层架构

- **数据层**：溯源案例库、攻击链数据集、威胁情报数据集、指令数据集
- **预训练层**：安全领域语料持续预训练
- **微调层**：指令微调 + 强化学习
- **增强层**：RAG检索增强、工具调用能力、知识图谱推理
- **应用层**：攻击链还原、威胁归因、时间线构建、报告生成

### 2.2 基座模型选型

| 场景 | 推荐模型 | 理由 |
|------|---------|------|
| 云端版本 | DeepSeek-V3 | 最强能力 |
| 私有化版本 | DeepSeek-V2.5 / Qwen2.5-72B | 性价比高 |
| 边缘版本 | Qwen2.5-32B | 轻量级 |

## 3. 数据层建设

### 3.1 数据集体系

| 数据集名称 | 规模 | 内容描述 |
|-----------|------|---------|
| 溯源案例库 | 10,000+ | APT报告、威胁情报、CVE分析 |
| 攻击链数据集 | 50,000+ | 结构化攻击链样本 |
| 威胁情报数据集 | 100,000+ | APT档案、恶意软件家族、IOC |
| 指令数据集 | 100,000+ | 多任务指令样本 |

### 3.2 数据标注规范

- 攻击链标注：步骤编号、战术、技术、描述、证据关联、置信度
- 证据标注：类型、来源、时间戳、IOC信息、关联说明
- 归因标注：威胁组织、置信度、匹配TTP/IOC、推理过程

---

## 4. 模型层建设

### 4.1 训练流程

**阶段一：持续预训练 (CPT)**
- 数据配比：安全通用语料60% + 溯源专用语料30% + 通用语料10%
- 学习率：1e-5，训练步数：50,000

**阶段二：监督微调 (SFT)**
- 攻击链还原：20,000样本
- 威胁归因：15,000样本
- 时间线构建：20,000样本
- 报告生成：10,000样本
- 使用 LoRA 微调 (r=64, alpha=128)

**阶段三：强化学习 (RLHF)**
- 安全专家反馈收集
- 奖励模型训练
- PPO/DPO 策略优化

---

## 5. 增强层建设

### 5.1 RAG 检索增强

- 溯源案例库向量检索
- 威胁情报知识库
- 多路召回 + 重排序

### 5.2 工具调用能力

- 证据收集：SIEM/EDR/流量/DNS查询
- 情报查询：威胁情报/APT档案
- 分析工具：时间线/IOC/TTP分析

### 5.3 多智能体协同

- 编排智能体、证据收集智能体、时间线智能体、攻击链智能体、归因智能体
