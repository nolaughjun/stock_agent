## 一、数据集整体规划

### 1.1 数据集体系架构

- **预训练数据集 (CPT)**: 50GB+ 文本数据，用于安全领域知识注入
- **指令微调数据集 (SFT)**: 100,000+ 指令样本，用于下游任务能力训练
- **偏好对齐数据集 (RLHF)**: 10,000+ 专家标注，用于对齐安全专家偏好
- **评估测试数据集**: 5,000+ 测试样本，用于模型性能评估

### 1.2 数据集规模规划

| 数据集类型 | 规模 | 格式 | 存储需求 |
|-----------|------|------|---------|
| 预训练语料 | 50GB+ | 纯文本 | 50GB |
| 指令数据集 | 100,000+ | JSONL | 10GB |
| 偏好数据集 | 10,000+ | JSONL | 2GB |
| 评估数据集 | 5,000+ | JSONL | 1GB |

## 二、预训练数据集准备

### 2.1 数据来源清单

【威胁情报来源】
- MITRE ATT&CK: TTP定义、攻击描述 (官网免费下载)
- MITRE CAPEC: 攻击模式 (官网免费下载)
- NVD (CVE): 漏洞描述 (API免费获取)
- CISA Advisories: 安全公告 (官网免费下载)

【厂商报告来源】
- Mandiant Reports: APT分析报告
- FireEye Threat Report: 威胁报告
- CrowdStrike Reports: 威胁情报
- Palo Alto Unit42: 威胁研究
- 奇安信威胁情报中心: 中文威胁报告
- 腾讯安全报告: 中文威胁报告

【安全知识来源】
- Security Whitepapers: 安全白皮书
- Security Blogs: 技术博客
- Academic Papers: 学术论文 (arXiv, IEEE)
- Security Standards: 安全标准 (ISO, NIST)

### 2.2 数据处理流程

Step 1: 原始数据收集 - 从各数据源下载原始文件
Step 2: 格式转换 - PDF/HTML/JSON转纯文本
Step 3: 数据清洗 - 去除无效字符、重复内容
Step 4: 数据去重 - 文档级/段落级去重
Step 5: 敏感信息处理 - IP/域名/个人信息脱敏
Step 6: 数据标注 - 添加来源标签、质量评分
Step 7: 数据统计 - 词频、质量评估

## 三、指令微调数据集准备

### 3.1 四大任务数据构建

任务一：攻击链还原 (20,000样本)
- 输入: 原始日志数据、事件描述、IOC列表
- 输出: 攻击链、入口点分析、置信度评分
- 来源: APT报告提取60%、真实案例脱敏25%、模拟攻击15%

任务二：威胁归因 (15,000样本)
- 输入: IOC列表、TTP特征、攻击手法描述
- 输出: 威胁组织名称、置信度、推理过程
- 来源: 威胁情报报告50%、APT档案库35%、历史案例15%

任务三：时间线构建 (20,000样本)
- 输入: 多源日志数据、时间范围、关注资产
- 输出: 时间线事件列表、关键事件标记
- 来源: 真实事件日志脱敏50%、攻击报告提取30%、模拟数据20%

任务四：溯源报告生成 (10,000样本)
- 输入: 分析结果(时间线+攻击链+归因)
- 输出: 事件概述、攻击链分析、处置建议
- 来源: 真实溯源报告脱敏60%、攻击分析报告30%

### 3.2 指令数据格式

{
  "instruction": "分析以下安全事件日志，还原攻击链",
  "input": {"logs": [...], "context": "..."},
  "output": {"attack_chain": [...], "confidence": 0.95},
  "task_type": "attack_chain_reconstruction",
  "difficulty": "medium",
  "source": "apt_report_001"
}

## 四、数据标注规范

### 4.1 攻击链标注规范

必填字段:
- step_id: 步骤序号
- tactic: MITRE ATT&CK战术
- technique: MITRE ATT&CK技术编号
- description: 步骤描述
- evidence_ids: 关联证据ID
- confidence: 置信度(0-1)

置信度评分标准:
- 0.9-1.0: 明确证据支持，多源验证
- 0.7-0.9: 有证据支持，存在不确定
- 0.5-0.7: 基于推理，证据不足
- 0.3-0.5: 推测性判断

### 4.2 威胁归因标注规范

必填字段:
- threat_actor: 威胁组织名称
- confidence: 置信度评分
- reasoning: 归因推理过程
- matched_ttps: 匹配的TTP列表
- matched_iocs: 匹配的IOC列表

## 五、数据增强策略

### 5.1 数据增强方法

方法一：同义词替换
- 攻击术语同义词库
- 恶意软件→恶意程序、恶意代码、病毒
- 横向移动→横向渗透、内网漫游

方法二：日志模板生成
- 从真实日志提取模板
- 替换IP/域名/时间等参数

方法三：攻击链组合
- 从多个真实案例提取攻击步骤
- 合理组合形成新攻击链

方法四：逆向生成
- 从已知APT组织TTP生成模拟攻击

方法五：翻译增强
- 中英文互译，保留技术术语

## 六、数据质量保障

### 6.1 质量检查清单

- 完整性: 必填字段是否填充
- 准确性: MITRE编号、时间戳格式是否正确
- 一致性: 攻击链步骤顺序是否合理
- 唯一性: 是否存在重复数据
- 安全性: 是否包含敏感信息
